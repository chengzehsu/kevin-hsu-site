# Hero 影片：35 秒發表風格短片

> 不會被網站渲染。場景原始檔：`scripts/launch-film.js`；算圖：`scripts/render-hero-reel.py`。

**定位**：去面試用，看的人是要決定「能不能把模糊的問題交給這個人」的產品主管，不是要買服務的客戶。前段讓能力雷達圖一路長大當證據；結尾只留一個記得住的習慣：「先讓它能跑，再讓它上線。」不列對方痛點、不推銷解法（那是廠商的口吻），也不自稱稀缺或「隆重介紹」。風格參考 Notion、Speak、YC 新創發表片：暗場、移動的主光、玻璃卡片、游標操作、彈性動畫。

## 結構

| 秒數       | 內容                                                                                                                                                                                                                                                      |
| ---------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 0～4       | 「產品卡住的地方，通常不在需求清單上。」接「而在沒人定義過的流程，和使用者沒說出口的痛點裡。」                                                                                                                                                            |
| 4～22      | v2019 到 v2025 版本卡片（2021 停 4.6 秒）；游標把每段的能力拖到能力雷達圖對應的角，多邊形一路長大。六軸對應網站核心技能：產品策略、使用者研究、流程與營運、資料與系統、團隊交付、AI 交付；AI 交付在 2025 最後拉滿。軸長是依經歷排的相對程度，畫面不標分數 |
| 22～25     | 雷達圖移到中央放大發光：「六段經歷，練成同一個習慣。」                                                                                                                                                                                              |
| 25～31.6   | 「給我一個模糊的問題，我還你一個能跑的版本。」三張步驟卡由左往右依序點亮（琥珀、青、綠），中間的箭頭先閃再亮下一張：現場（3 週驗證香港市場）→ 原型（2 個月 218 次提交）→ 交付（交付效率 +50%）                                                                                                                                                                      |
| 31.6～34.4 | 署名：名字、職稱、「先讓它能跑，再讓它上線。」                                                                                                                                                                                                        |

數字只用網站已公開的；揀貨固定寫「300 → 1,000 單／日 (+233%)」，只出現在 2021 卡片的數字，不再做全螢幕特寫（原本 10.6～12 秒的藍光「+233%」打斷雷達圖的節奏，已拿掉）。「一週 → 2 小時」「名片建檔 −99%」尚未確認能公開，不要放進影片。影片裡的文字網站的文字檢查掃不到，改文案時要自己核對破折號與揀貨寫法。

## 製作

- 產出：`public/hero-reel.{zh,en}.{webm,mp4}`（webm 約 1.6 MB、mp4 約 3.1 MB，yuv420p 一般色彩範圍）、`public/hero-reel-poster(-small).{zh,en}.webp`（第 33.2 秒署名那格）。
- 重算：在沙箱外執行 `python3 scripts/render-hero-reel.py frames <dir> [--lang en]`，再用 ffmpeg 壓縮：960×600、24fps，必須輸出 yuv420p 一般色彩範圍（JPEG 截圖直接轉會變成 yuvj420p，Safari／QuickTime 會出問題），x264 用 crf 19 加 aq-mode 3 以避免暗部條紋。
- 網站：`HeroFilm` 依語系播放；影片下方只有一段 sr-only 的完整敘述（`hero.film.summary`）和生鮮電商案例連結。
